# SoftNet CardForge Android — Kotlin / Android 15

مشروع Android Studio بلغة Kotlin، مضبوط على `compileSdk 35` و`targetSdk 35` (Android 15).

## مهم قبل الاستخدام
هذا تطبيق Android مرافق لواجهة V58، وليس نقلًا مستقلًا لخادم Python إلى الهاتف. يجب تشغيل **SoftNet CardForge Web V58** على كمبيوتر Windows أو خادم داخل الشبكة، ثم توصيل الهاتف بنفس الشبكة المحلية.

## إعداد الاتصال
1. شغّل V58 على الكمبيوتر باستخدام `START_V58.bat`.
2. اعرف عنوان IPv4 للكمبيوتر من `ipconfig` (مثل `192.168.88.10`).
3. اسمح بالمنفذ 8080 في Windows Firewall للشبكة الخاصة عند الحاجة.
4. تأكد أن الهاتف والكمبيوتر على نفس شبكة Wi-Fi.
5. افتح التطبيق واكتب `http://عنوان-الكمبيوتر:8080`، مثال `http://192.168.88.10:8080`.
6. إذا شغّل V58 على منفذ 8081 بسبب وجود نسخة أخرى، استخدم `:8081`.

## بناء APK
1. افتح مجلد المشروع `SoftNetCardForgeAndroid` في Android Studio حديث يدعم Android SDK 35.
2. انتظر مزامنة Gradle.
3. من القائمة: **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. ملف APK التجريبي يظهر عادةً في `app/build/outputs/apk/debug/app-debug.apk`.

## الوظائف
- عرض واجهة V58 الحالية داخل تطبيق Android.
- حفظ عنوان الخادم محليًا داخل الهاتف.
- أزرار تحديث/رجوع/الرئيسية.
- فتح روابط واتساب الخارجية في التطبيق أو المتصفح المناسب.
- إعداد Android 15 (API 35)، مع دعم Android 6.0 فما فوق.

## حدود هذا الإصدار
- يجب أن يظل خادم V58 يعمل على الكمبيوتر.
- إعدادات اتصال الميكروتك تبقى في خادم V58.
- HTTP مسموح لتوافق الخادم المحلي؛ استخدم شبكة موثوقة ولا تعرض الخادم للإنترنت العام.
